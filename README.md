# UE5Recipes
Recipes for Unreal Engine 5 to enable everyone to get started with game development with Unreal Engine 5.

## Before you start

Each project in this repo, including Blueprint recipes, is a C++ project. After you clone it to your machine, you need Unreal Engine to generate the solution files. Simply right-click on the .uproject file and select "Generate Visual Studio project files"; see the image here:

![image-20260426195312760](mdAssets/image-20260426195312760.png)

## Running the Unreal Editor

Once this is done, double-click the newly created .sln file to open Visual Studio. To start the Unreal Editor, press CTRL+F5 in Visual Studio (Start without debugging).
